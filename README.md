# XZCode

XZCode 是一款 Windows 桌面端 ZCode 多账号管理工具，基于 Electron 开发，主要用于集中管理、注册、切换和维护多个 ZCode 账号。

## 主要功能

- **多账号隔离**：每个账号使用独立的凭据、配置、日志和浏览器会话，切换时互不覆盖。
- **快速切换账号**：选择账号后自动关闭旧客户端，并使用目标账号环境重新启动 ZCode。
- **Z.ai 自动注册**：自动填写注册信息，支持配合临时邮箱完成收信、激活和授权流程。
- **临时邮箱收信**：可在设置中填写用户自己的 YYDS Mail API Key，自动创建临时邮箱、接收验证邮件并提取激活链接。未填写 API Key 时可改为人工输入邮箱和激活链接。
- **Z.ai OAuth 登录**：已有 Z.ai 账号可直接通过浏览器完成 OAuth 授权并导入面板。
- **BigModel 登录**：支持手机号、短信验证码和网页授权流程。
- **一键领取额度**：批量检查账号可领取的额外额度，并自动执行领取。
- **套餐与余额查询**：查看各账号的套餐、每日额度、已使用额度和剩余额度。
- **账号导入导出**：支持导入外部账号，并以 JSON 或 CSV 格式导出备份。
- **批量维护账号**：支持识别和清理过期账号，删除时先移入回收目录，降低误删风险。
- **代理配置**：可读取并同步 Windows 系统代理，解决 ZCode 客户端默认直连的问题。
- **会话索引同步**：切换账号后仍可继续访问共享的项目和历史会话。

## Z.ai 邮箱注册

邮箱注册需要先开启代理并连接到境外节点。点击“Z.ai 邮箱注册”时，程序会先显示代理确认提示。

如需自动收取激活邮件，请在设置中填写自己的 YYDS Mail API Key。API Key 由用户自行申请和保管，项目源码中不包含任何预置密钥。

## 使用要求

- Windows 10 1809 及以上或 Windows 11，x64
- 已安装 ZCode 桌面客户端
- 使用自动邮箱注册时，需要用户自己的 YYDS Mail API Key
- Z.ai 邮箱注册需要可用的境外代理

## 运行

普通用户可从 [Releases](https://github.com/8797a/Xzcode/releases) 下载便携版，双击运行。

从源码运行：

```bash
npm install
npm start
```

构建 Windows x64 版本：

```bash
npm run dist
```

## 数据与隐私

XZCode 采用本地优先设计，账号资料保存在用户自己的电脑中。仓库不包含账号、邮箱、密码、API Key 或访问令牌。请勿公开上传运行后生成的账号目录或账号导出备份。
